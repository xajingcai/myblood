# 运动与游泳：就诊讨论清单

这是讨论工具，不代表已获得运动许可。个体判断和状态存 private/follow-ups/。

- [ ] 当前血压是否稳定，是否可以开始有氧训练？
- [ ] 从步行或固定自行车开始是否更合适？每次多久、如何增加？
- [ ] 能否游泳？是否有心脏、肾脏或其他限制？
- [ ] 运动前什么血压水平需要暂停？出现什么症状要停止并就医？
- [ ] 是否需要运动检查？是否应设个人心率范围？
- [ ] 如果处方影响心率，怎样用呼吸和主观用力程度调整强度？

## 阅读材料
- [AHA：运动与高血压](https://www.heart.org/en/health-topics/high-blood-pressure/changes-you-can-make-to-manage-high-blood-pressure/getting-active-to-control-high-blood-pressure)：循序渐进、热身和放松，规律呼吸；心率不能替代血压与症状评估。
- [国家卫健委：高血压运动注意事项](https://www.nhc.gov.cn/xcs/nwwd/202003/0baf9e21fc4a4fee8d24e275fe61f17f.shtml)：血压未控制或不稳定时先评估，避免憋气、爆发用力。
- [BHF：游泳与心脏健康](https://www.bhf.org.uk/informationsupport/heart-matters-magazine/activity/swimming-with-a-heart-condition)：水温与水中运动注意事项，避免长时间憋气；材料面向心脏病人群，不能直接视为所有高血压患者的处方。

来源于2026-11-02同日已检索材料；血压控制后游泳可以是选项，但不能仅凭年龄公式或运动手表心率判定安全。
