# 待跟进事项

本目录保存可上传的流程和空白模板。真实预约、检查结果、药物和个人任务状态放在本地 private/follow-ups/，不随 Git 上传。

- [就诊准备与诊后跟进模板](doctor-visit-template.md)
- [运动与游泳讨论清单](exercise-discussion.md)

## 维护约定
每项记录：事项、状态、下一步、期限（未知就写待定）、依据和完成结果。
状态使用：待处理 / 进行中 / 等待外部结果 / 已完成。预约成功不等于已就诊；做过检查不等于已审阅结果。
就诊后按医嘱更新任务，不自行设定药物或运动强度。完成后保留结论与日期，便于追溯。
本目录是记录清单，不会自动发送提醒；如需提醒，需另外设置。
