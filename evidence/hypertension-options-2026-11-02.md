# 改善高血压：证据与适用边界

整理日期：2026-11-02。本文为定向资料整理，不是穷尽式系统综述。优先中国官方指导、国际指南和原始随机试验。网页部分受访问限制，见来源核对说明。

## 证据摘要

| 方向 | 依据和可合理期待的效果 | 限制 |
|---|---|---|
| 减重 | 2025 AHA/ACC指南以持续减重至少5%为超重人群目标之一；群体平均每减1kg，收缩压约降1mmHg。[S1] | 不能线性外推到个人，也不保证低压同幅度下降 |
| DASH饮食 | 指南表12估计高血压人群收缩压平均降低约5–8mmHg。[S1] | 饮食执行程度、基线、用药及研究设计不同，不能直接预测个人 |
| 减钠 | 指南表12估计高血压人群收缩压平均降低约6–8mmHg。[S1] | 与DASH、减重的作用重叠，不能相加 |
| 低钠＋DASH | DASH-Sodium随机试验412人，每个钠水平阶段30天；高血压亚组相对高钠对照饮食，收缩压低11.5mmHg。[S2] | 供餐试验，入组血压120–159/80–95范围；不代表舒张压105–115者的预期或可替代药物 |
| 规律运动 | 指南支持有氧运动，稳定后逐步达到每周150分钟中等强度。[S1][S3] | 血压未控制时需先评估，不能直接照搬一般运动量 |
| 睡眠 | 有打鼾、呼吸暂停、喘醒等线索时，评估睡眠呼吸暂停。[S6] | 单次夜醒不诊断失眠，白天精神好也不能排除呼吸暂停；没有通用个人降压数字 |
| 规范治疗 | 持续2级高血压通常需药物配合生活方式；40岁以下考虑专科评估继发原因。[S4] | 药物选择与目标取决于肾功能、血钾、合并症及耐受性 |

表中都是群体证据，SBP=收缩压；不是个人预测区间，不能相加。未列量化效应不代表无效，而是本资料不提供未经核实的数字。

## 具体执行工具

### 饮食
按DASH模式选择蔬菜、水果、全谷物、豆类、鱼禽和低脂乳制品，减少高饱和脂肪食物和含糖饮料。[S5]
实用改法：外卖要求酱汁另放，少喝汤；加工肉和咸菜换成新鲜食物；用无糖饮品代替甜饮；将一部分精制主食换成全谷物。这些是便于执行的转化建议，不是单独验证过的降压处方。

中国指导建议每日总食盐逐步少于5g，含烹调用盐与加工食品、酱油等隐形盐。[S3] 食盐5g约含钠2000mg；读标签时看每份重量及钠含量，不能把“钠”与“盐”混用。
肾功能、血钾或相关用药不明时，不自行补钾或换含钾代盐。[S1]

### 活动
先评估再逐步增加。中国官方发布的指导材料指出，运动前收缩压超过180或舒张压超过110mmHg，应控制后再进行运动。[S3]
达到合适条件后，可讨论从短时步行逐步增加到常规有氧目标；具体强度由医生结合血压与健康情况确定。不要靠大量出汗、憋气用力或突然高强度训练快速降压。

### 记录
固定测量时间与手臂、使用合适袖带；安静休息至少5分钟，每次两遍、间隔1分钟，保留原值。[S7]
同时记录用药变化、体重、睡眠、饮食和活动，以免把测量误差或药物效果误认作某个生活措施的效果。
