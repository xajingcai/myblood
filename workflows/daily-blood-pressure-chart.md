# 每日血压走势图

Codex 在当前聊天中设置了本地自动任务，每天北京时间 08:00 生成走势图。调度由 Codex 管理，本文件记录任务约定。

- 从本地 `private/readings.json` 读取最近 14 天已确认且纳入统计的读数。
- 早晚读数放在同一张图，横轴标注日期和早晚，纵轴单位为 mmHg。蓝色表示收缩压，橙色表示舒张压。
- 实心点表示已录入的正式读数。空心点表示日期和时段明确、但尚待确认的自述。待确认读数仅供对照，不计入均值或样本数。
- 各点独立展示，标明缺测和样本数。缺日期或时段的自述列在图注中。
- 无新增读数时仍生成当日图，并注明数据未更新。
- 图表保存在本地 `private/charts/`，并显示在聊天中。个人记录和图表由 Git 忽略。
- 若读取或绘图失败，在聊天中说明原因。

录入新读数时，记录实际测量日期、时间、两次读数和服药时间。详见[记录说明](../data/README.md)。
