# 预测规则

当前状态：没有个人数据，不生成个体数值预测。

区分：①研究群体效应；②基于假设的个人情景估计；③经过前瞻检验的个人预测。
默认关注未来7天家庭血压日均值的平均，而非某一次读数；必须明确收缩压和舒张压分别预测。
7天记录只是描述起点，不自动代表足够预测。需评估缺失、稳定性、测量条件、用药变化与实际执行情况。

每个预测先用 template.md 登记并提交，再等待真实结局。预测区间需有可复核方法和校准依据；不能凭空编造95%区间。
最初可建立“未来维持近期均值”的朴素基线；任何复杂方法必须与其比较。外部研究效应不能直接相加。
前瞻评估记录绝对误差、系统偏差、区间覆盖率（如有区间）及样本数。连续重叠窗口有相关性，不当独立试验。
实际变化可能由回归均值、测量差异、药物或其他变化导致，不能单凭前后对比认定因果。
